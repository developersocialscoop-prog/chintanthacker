## 📖 Overview

A full-featured personal portfolio showcasing the founder's journey, services, and 30+ projects across 10 digital disciplines. Built with modern React, animated with Framer Motion, and enhanced with WebGL backgrounds.

**Built for:** Personal branding, client acquisition, and credibility building.

---

## ✨ Features

### Visual & Interactive
- 🌌 **Galaxy Background** — WebGL-animated starfield in the Hero (React Bits)
- ✨ **Gradient Text Animation** — Animated name using Framer Motion
- 🪪 **3D Lanyard Card** — Interactive 3D ID card in the About section (Three.js + Rapier physics)
- 🎞️ **Circular Gallery** — Infinite 3D image carousel (OGL)
- 🎯 **Before/After Slider** — Drag-to-compare transformation slider

### Content Sections
- **Hero** — Name, tagline, CTA
- **Trust Bar** — Client logos + key stats
- **Journey (Shift)** — Founder story with before/after slider
- **About** — Bio + 3D Lanyard card + image gallery
- **Approach** — 4-step process
- **Services** — 11 services in a filterable grid
- **Portfolio** — 30+ projects with category filters + load more
- **Testimonials** *(coming soon)*
- **Team** *(coming soon)*
- **Timeline** *(coming soon)*
- **Instagram Feed** *(coming soon)*
- **Contact** *(coming soon)*
- **Footer** *(coming soon)*

### Developer Experience
- ⚡ **Vite** — Lightning-fast dev server & build
- 🎨 **Tailwind CSS v4** — Utility-first styling with `@theme` tokens
- 🎬 **Framer Motion** — Smooth, accessible animations
- 🧩 **Modular Sections** — Each section has its own `.jsx` + `.css`
- 📱 **Mobile-First Responsive** — Breakpoints from 320px → 1920px+
- ♿ **Accessible** — ARIA labels, keyboard navigation, reduced motion support
- 🐳 **Docker-Ready** — Multi-stage build for production
